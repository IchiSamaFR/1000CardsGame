# Jeu des 1 000 cartes blanches

Jeu d'ambiance (aussi appelé **1KBWC**) dont les cartes sont **inventées par les joueurs pendant la partie**. Créativité et humour priment sur le score.

- Joueurs : illimité
- Âge : enfants comme adultes
- Durée : variable (jusqu'à épuisement de la pioche)
